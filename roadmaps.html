Learning Roadmaps

Simple first steps for beginners in each field. Follow them in order.

Web Development

  1. Learn HTML and CSS
  2. Learn JavaScript
  3. Learn a framework
  4. Build your own projects

Software Development

  1. Pick a language (Python, Java or C#)
  2. Learn algorithms and data structures
  3. Learn Git
  4. Build small programs

Cybersecurity

  1. Learn networking basics
  2. Learn Linux basics
  3. Learn security concepts
  4. Practice in safe labs

Artificial Intelligence

  1. Learn Python
  2. Learn basic math and statistics
  3. Learn machine learning basics
  4. Build mini projects

Networking

  1. Learn how the internet works
  2. Learn IP addresses and subnetting
  3. Learn routers and switches
  4. Practice with Packet Tracer

Data Science

  1. Learn Python
  2. Learn statistics
  3. Learn data analysis tools
  4. Practice data visualization

Cloud Computing

  1. Learn Linux basics
  2. Learn cloud concepts
  3. Pick a provider (AWS, Azure or Google Cloud)
  4. Deploy a small app
