About IT Compass

A small educational website made to help beginners find their way into IT.

Purpose

IT has many fields and it is hard to know where to start. This site explains the main ones in simple words.

Who it's for

Students and complete beginners who want to understand what each IT specialization involves.

The project

Built as a first-year university web development project, using only HTML and CSS.
